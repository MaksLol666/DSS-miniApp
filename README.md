# Dead Smoke Store — Telegram Mini App

Переписанный Telegram-магазин на FastAPI, aiogram и SQLite. Интерфейс — обычный HTML/CSS/JavaScript, без React/Vite/npm build; FastAPI отдаёт его напрямую из static/index.html.

## Функции

- Каталог с категориями, поиском, товарами и контролем наличия.
- Корзина и применение до двух промокодов на заказ; выбранные коды теперь сохраняются в SQLite между перезапусками.
- Оформление с самовывозом или доставкой СДЭК за 500 ₽.
- История заказов и статусы; покупка подтверждается администратором.
- Профиль, активные промокоды, реферальная ссылка, топ покупателей и топ реферов.
- Реферальный бонус 15% от первой подтверждённой покупки приглашённого и скидка −10% за каждые 10 рефералов с покупками.
- Отзывы к подтверждённым заказам с публикацией в Telegram-канал.
- Админ-панель Mini App: добавление/редактирование/архивация товаров, подтверждение/отклонение заказов, поиск пользователей, блокировка/разблокировка, сброс статистики, промокоды, статистика и рассылка.
- Команды бота /start, /admin, /help и уведомления об оформленных заказах.
- Проверка Telegram initData, ограничение частоты запросов и опциональная DDoS-Guard dCAPTCHA.

## Запуск на Bothost

- Точка запуска контейнера: `python main.py`; приложение слушает порт `3000` (или значение переменной окружения `PORT`).
- Рабочий публичный URL Mini App: https://dss-mm-shop.bothost.tech/
- Значение `MINIAPP_URL` в настройках окружения Bothost тоже должно быть `https://dss-mm-shop.bothost.tech/`, чтобы кнопка запуска Mini App и ссылки в боте вели на новый домен.
- Проверка API: `/health` или `/api/health` должна возвращать JSON `{"ok":true,"app":"dss-miniapp"}`. Корень `/` отдаёт `static/index.html`.
- После коммита в ветку `main` обнови контейнер в Bothost.

## Environment

Настрой в Bothost `BOT_TOKEN`, `ADMIN_ID`, `MINIAPP_URL`, `DB_URL`; значения для CAPTCHA — `DDOS_GUARD_SITE_KEY`, `DDOS_GUARD_SECRET_KEY`, `DDOS_GUARD_SESSION_SECRET`. Секретный ключ CAPTCHA и токен Telegram не отправляй в чат и не коммить в GitHub.

## Сохранность данных

Модели сохраняют имена и поля существующих таблиц пользователей, категорий, товаров, корзины, заказов, строк заказов, промокодов и отзывов. Startup создаёт отсутствующие таблицы и мигрирует недостающие поля доставки/блокировок. Новая таблица cart_promos хранит применённые к корзине промокоды. Товары, встречающиеся в истории заказов, скрываются вместо удаления, чтобы история не сломалась.

У старой версии в истории Git уже был файл .env; если это ещё не сделано, отзови старый токен через BotFather и обнови BOT_TOKEN в Bothost.
